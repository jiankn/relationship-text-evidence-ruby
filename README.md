# Relationship Text Evidence

A small Ruby reference for describing observable messaging patterns while keeping interpretation separate from measurement.

For a structured example, see the [reply time calculator](https://whathethinks.com/reply-time-calculator) on WhatHeThinks.

## Principles

- compare trends over several conversations;
- treat overnight and work-hour gaps separately;
- compare both participants;
- include evidence that contradicts the initial hypothesis;
- never treat response time alone as proof of interest.
